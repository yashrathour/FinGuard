How scoring works

Each row is sent to the FastAPI backend () at /score/batch. The backend scales features, applies PCA, asks XGBoost for a fraud probability and the Autoencoder for a reconstruction-error anomaly score, then blends the two (0.7 / 0.3). Inputs land in transactions and outputs in fraud_predictions — both in your Supabase project.

If the backend is offline we still run a fast heuristic scorer in the browser so the demo works end-to-end. Start the backend with uvicorn main:app --port 8000 to use the real ensemble.
